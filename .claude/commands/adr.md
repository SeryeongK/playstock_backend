# 기술 의사결정 기록

방금 또는 최근 대화에서 내린 기술 의사결정을 `decision-logger` 서브에이전트를 통해 ADR(Architecture Decision Record) 형식으로 `docs/decisions/`에 저장하라.

## 결정 주제
$ARGUMENTS

## 추출해야 할 정보
1. **컨텍스트** — 왜 이 결정이 필요했는가
2. **검토한 옵션** — 최소 2개, 각각 장단점
3. **선택한 옵션** — 무엇을, 왜
4. **트레이드오프** — 무엇을 포기했나
5. **재검토 조건** — 언제 다시 봐야 하나

대화 컨텍스트가 부족하면 사용자에게 한두 가지만 추가 질문하라 (옵션은 최대 4개 버튼 형태로).

## 출력
저장된 ADR 파일 경로 + INDEX.md 갱신 확인 메시지.
