# 학습 노트 정리

지금까지의 대화에서 학습 포인트(개념, 문법, 패턴, 원리에 관한 Q&A)를 모두 추출하여 `learning-note-keeper` 서브에이전트를 통해 카테고리별 파일에 일괄 저장하라.

## 추출 기준
- "X가 뭐야?" 같은 개념 질문과 답변
- "X와 Y의 차이는?" 비교 질문과 답변
- "X는 왜 필요해?" 원리 질문과 답변
- 코드를 짜면서 발견한 동작 방식, 어노테이션의 의미, 패턴 등

## 제외 기준
- 단순 코드 작성 요청 (학습성 아님)
- 의사결정 토론 (이건 decision-logger 영역)
- 진행 상황 공유, 일정 논의

## 출력
- 저장된 파일 목록을 짧게 보고
- 추가 정리가 필요해 보이는 항목 있으면 제안
