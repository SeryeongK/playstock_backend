# 테스트 작성

`test-writer` 서브에이전트를 호출하여 테스트를 작성하라.

## 대상
$ARGUMENTS

## 모드 결정
- `tdd` 키워드가 있거나, 구현 클래스가 아직 없으면 → **TDD 모드**
- `after` 키워드가 있거나, 이미 구현이 완료된 코드면 → **사후 테스트 모드**
- 명시 없으면 사용자에게 확인 (단, 사기 탐지 룰은 무조건 TDD 모드)

## 필수 시나리오
- 정상 케이스 최소 1개
- 위반/예외 케이스 최소 1개
- 엣지 케이스 (경계값, null, 0 등) 최소 1개

## 출력
1. 테스트 파일 경로
2. 작성된 테스트 메서드 목록
3. 실행 결과 (`./gradlew test --tests {클래스명}`)
4. TDD 모드면 다음 단계 안내
