# 작업 쪼개기

다음 작업을 AI 협업에 적합한 작은 유스케이스 단위로 쪼개라:

**작업:** $ARGUMENTS

## 쪼개기 원칙
1. **한 단위 = 한 클래스 또는 한 메서드 또는 한 엔드포인트**
2. **AI에게 한 번에 시키기 좋은 크기** (출력 100줄 이내)
3. **순서가 있는 단위는 의존성 명시** (예: "엔티티 → Repository → Service → Controller")
4. **테스트도 별도 단위로** (구현 후 테스트가 별도)

## 출력 포맷
```
## {작업명} 쪼개기

### Step 1: {유스케이스}
- 산출물: {파일/메서드}
- AI에게 던질 프롬프트 예시: "..."
- 의존성: 없음

### Step 2: {유스케이스}
- 산출물: ...
- AI에게 던질 프롬프트 예시: "..."
- 의존성: Step 1

...

## 진행 권장 순서
1 → 2 → 3 → ...

## 예상 소요
대략 N시간
```

## 주의
- 단계가 5개 이상 나오면 너무 큰 작업. 더 작게 쪼개거나 범위 축소 제안.
- "다 한 번에 짜줘" 식의 제안은 절대 금지.
- 사용자가 PHP→Java 전환 중인 점 고려, 익숙하지 않은 부분은 별도 학습 단계로 명시.
