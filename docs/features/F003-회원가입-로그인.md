## 1. 설계 (Why & What)

### 목적
모든 보호 API의 선행 조건인 인증 레이어를 구축한다. Stateless JWT 방식으로 서버 세션 없이 사용자를 식별하고, 이후 기능(채널 등록, 거래, 배당)에서 `@AuthenticationPrincipal Long userId`로 호출자를 바로 꺼낼 수 있게 한다.

### 입력 / 출력
- 입력: 이메일·닉네임·비밀번호·role (회원가입) / 이메일·비밀번호 (로그인)
- 출력: 201 Created + userId (회원가입) / 200 OK + JWT 액세스 토큰 (로그인)

### 핵심 흐름
1. **회원가입** — 이메일 중복 체크 → BCrypt 암호화 → `users` 테이블 저장 → 201
2. **로그인** — 이메일로 사용자 조회 → BCrypt 비교 → JWT 발급 (payload: userId + role) → 200
3. **보호 API 접근** — `Authorization: Bearer {token}` 헤더 → `JwtAuthenticationFilter` → `SecurityContextHolder`에 `userId(Long)` + role 등록 → Controller에서 `@AuthenticationPrincipal` 로 꺼냄

### 주요 결정
- Spring Security Stateless (세션 없음) + CSRF disable. 이유는 [security.md](../learning-notes/security.md) 참고.
- JWT payload에 userId + role 포함 → DB 조회 없이 인증 처리.
- jjwt 0.12.6, HMAC-SHA256 (HS256). Secret은 32자 이상 환경변수 필수.

## 2. 구현 (How)

### 패키지
`com.playstock.user`, `com.playstock.common`, `com.playstock.common.config`

### 파일 목록
- `user/User.java` — 엔티티. `@PrePersist`로 `createdAt`·`pointBalance(0)` 초기화.
- `user/UserRole.java` — INVESTOR / CREATOR / ADMIN
- `user/UserRepository.java` — `findByEmail`, `existsByEmail`
- `user/SignupRequest.java` / `SignupResponse.java` — 회원가입 DTO
- `user/SignupService.java` — 이메일 중복 체크 + BCrypt + 저장
- `user/LoginRequest.java` / `LoginResponse.java` — 로그인 DTO (토큰 포함)
- `user/LoginService.java` — 비밀번호 검증 + JWT 발급
- `user/AuthController.java` — POST /auth/signup, POST /auth/login
- `common/JwtUtil.java` — 토큰 생성·검증·파싱
- `common/config/SecurityConfig.java` — Stateless, CSRF disable, 공개/보호 경로 분리
- `common/config/JwtAuthenticationFilter.java` — 매 요청마다 JWT 검증 후 SecurityContext 등록

### DB 변경
`users` 테이블 사용 (V1__init_schema.sql에서 이미 생성). 이 기능에서 추가 마이그레이션 없음.

### 의존성
- 선행 기능: F001 (공통 응답 포맷), F002 (users 테이블)
- 외부 API: 없음
- 라이브러리: Spring Security, `io.jsonwebtoken:jjwt` 0.12.6

### 핵심 코드 (스니펫)
```java
// JwtAuthenticationFilter — userId를 principal로 주입하는 핵심 구조
Long userId = jwtUtil.getUserId(token);
UserRole role = jwtUtil.getRole(token);
UsernamePasswordAuthenticationToken authentication =
    new UsernamePasswordAuthenticationToken(userId, null,
        List.of(new SimpleGrantedAuthority("ROLE_" + role.name())));
SecurityContextHolder.getContext().setAuthentication(authentication);
```

### 테스트

### 수동 검증
- [ ] POST /auth/signup — 정상: 201 + `{ data: { id, email, nickname } }`
- [ ] POST /auth/signup — 중복 이메일: 409 + `{ error: { code: "DUPLICATE_EMAIL" } }`
- [ ] POST /auth/login — 정상: 200 + `{ data: { token } }`
