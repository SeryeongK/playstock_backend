## 2026-05-16

### Q. Flyway가 뭐야?

**A.** DB 마이그레이션 도구. SQL 파일로 스키마(테이블 구조) 변경 이력을 관리.

**동작 방식:**
```
V1__init_schema.sql  ← 첫 실행 시 자동 실행 → 테이블 생성
V2__add_column.sql   ← 다음 실행 시 V2만 실행, V1은 스킵
V3__add_index.sql    ← ...
```

- 앱 시작 시 `flyway_schema_history` 테이블을 보고 어디까지 실행했는지 확인
- 실행 안 된 파일만 골라서 순서대로 실행
- 이미 실행된 파일은 재실행 안 함 → 재시작해도 기존 데이터 안전

**핵심 규칙:**
- 한 번 실행된 파일 절대 수정 금지 → 체크섬 불일치로 앱 기동 실패
- 변경이 필요하면 항상 새 파일(`V2__`)로 추가

**Flyway가 관리하는 것 vs 아닌 것:**
- 관할: 테이블 생성/수정/삭제 (DDL — 스키마)
- 무관: 테이블 안의 데이터 (INSERT/UPDATE/DELETE)

**기억 포인트:** Flyway = 스키마 버전 관리. 데이터는 건드리지 않음. 팀원이 코드 받아서 실행하면 DB가 자동으로 최신 상태가 됨.
